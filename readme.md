# SFML.Net - Simple and Fast Multimedia Library for .Net

Unofficial repository with some improvements. The changes are not backwards compatible. [Nuget Link](https://www.nuget.org/packages/SFML.Gaiden)

Last commit: https://github.com/SFML/SFML.Net/commit/d3bcfeb2a6f29336f9f64d8eccac8d389a967997

## Most notable changes

* Migrate to `net10`
* `Nullable` warnings as errors
* Use `Span`
* `sealed` classes
* `DllImport` converted to `LibraryImport`
* Move `P/Invoke` methods to CSFML* related classes.
